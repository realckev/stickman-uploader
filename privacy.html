Privacy policy

Last updated: October 24, 2026

Stickman Uploader is a private tool run by cKev INC for its own YouTube channels only.

What it accesses

With the channel owner's permission, it uses the YouTube Data API and the YouTube Analytics API to upload and schedule videos, set their thumbnails, and read view and retention statistics for the owner's own channels.

What it stores

The sign-in token for each channel is stored only on the owner's own computer. No Google user data is stored anywhere else, sold, or shared with anyone.

Google API Services

Stickman Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
